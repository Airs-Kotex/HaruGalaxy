# TrollStore 兼容性记录

目标是覆盖 TrollStore 用户的设备组合，代码不按 iPhone 14 Pro Max 硬编码。宿主安装范围与窗口后端能力分开记录，不能仅凭可编译或可安装就宣称全部兼容。

| 系统范围 | HaruGalaxy 0.3.1 宿主构建目标 | 外部窗口/后台状态 |
| --- | --- | --- |
| iOS/iPadOS 14.x（TrollStore 支持版本） | 包含，iOS 14 样式回退 | 接口检测；上游 FrontBoard 已知限制，未实测 |
| 15.x | 包含，动态接口检查 | 未实测 |
| 16.0–16.6.1 | 包含 | iPhone 14 Pro Max / 16.2：后台可用；0.3.0反馈输入/比例/下半屏与手感问题，0.3.1待复测 |
| 16.7 RC（20H18） | 包含 | 未实测 |
| 17.0 | 包含 | 未实测 |

以上依据 [TrollStore 官方支持范围](https://github.com/opa334/TrollStore#trollstore)：14.0 beta 2–16.6.1、16.7 RC（20H18）、17.0。不包括一般的 16.7.x 或 17.0.1 及以后版本。

当前仅构建 arm64，适用于该范围内的 64 位 iPhone/iPad 应用目标；未声明所有硬件组合均已验证。iPad、不同显示缩放、横竖屏和外接输入需要单独记录。

日志环境段提供机器型号、精确系统 build、关键 selector 可用性及相关 entitlements 观察值；事件段记录接口实际调用和系统拒绝/失效情况。接口存在也不等于系统允许调用，须结合实际结果。
