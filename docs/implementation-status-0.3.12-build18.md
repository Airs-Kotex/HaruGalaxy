# 0.3.12 build18 半屏贴边、可见兼容入口和图解

按用户明确要求，本轮合并到已发布0.3.12，内部build17→18，替换原发布附件并把tag指向合并后的源码提交；不发布0.3.13。旧发布元数据和6个附件已本地备份且摘要核对，0.3.11继续撤回。

用户希望半屏恢复完整顶部占用。0.3.12外框已经是准确半屏，但MWWindowView对所有非全屏窗口加safeTop，导致吸附上半屏也有47/59pt整块顶部空白。本版抽出MWWindowTitlePlacement：吸附时不移frame、extra title inset为0；普通窗口保留短窗可触达修正，最大化/挂起仍无顶栏。脱离吸附不再移除不存在的extra spacer，后续普通布局和等比缩放保护沿用。

纯C测试覆盖四个snap方向、三组视口/安全区、旋转、全屏还原、挂起还原，以及普通窗口保护。旧safe-top行为先复现顶栏y不为0，再验证新policy。设备顶部手势/物理遮挡未由本地验证，内容仍有系统安全区传递。

用户同时找不到省略号内的兼容入口。面板顶部增加第三个文字按钮，打开MWDisplayOptionsController显式列表，提示切换会重建会话；选择后先dismiss，再调用已有reopen路径。回调核对列表建立时的精确目标对象，现有隐藏/锁屏/pending检查避免陈旧回调作用于新窗口。列表不保存文字草稿、不接触键盘或其他App数据。

用户要求GitHub图片。当前没有iOS设备/模拟器图像，因此提供四张确定性绘制的操作示意PNG并明确标注。图解展示实际操作路径，抽象示例内容，不从诊断/第三方App取图。脚本和图解说明保留以便重建，字体文件不分发。视觉复核检查文字重叠/裁切及入口一致性；这些不作为真实UIKit渲染证据。
