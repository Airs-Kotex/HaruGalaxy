# 0.3.12 build18 半屏顶栏与入口检查

版本0.3.12/build18。此版按用户偏好让吸附半屏的顶栏贴半屏上沿，同时提供面板顶部“兼容显示”入口。

| 检查 | 操作与预期 |
| --- | --- |
| 上半屏 | 竖屏吸附上半屏，顶栏位于该半屏最上沿，不再下移47/59pt；外框仍准确占半屏 |
| 下半屏/横屏 | 下半屏顶栏位于屏幕中线；横屏左右半屏顶栏位于各自上沿 |
| 状态恢复 | 半屏→全屏→还原、半屏→挂起→还原、横竖屏切换后仍贴半屏上沿 |
| 脱离吸附 | 拖动或四角缩放退出半屏后恢复普通窗口顶部保护；取消动作恢复原半屏 |
| 物理遮挡 | 动态岛/刘海与系统顶部手势可能影响极顶部控件；可用面板管理，勿将示意图视为硬件无遮挡证据 |
| 显式兼容入口 | 边缘入口→面板顶部“兼容显示”→已有App列表→选择兼容重开；不需要先找省略号 |
| 列表为空 | 没有小窗时显示先打开应用的提示；不尝试重开不存在的窗口 |
| 兼容取消 | 关闭列表不改动窗口；窗口在列表出现后关闭/替换或锁屏，不应由旧回调重开 |
| 文档图 | GitHub README四张图可加载，文字明确标记示意图，非真机截图 |

日志中window.controls_installed.layout为four_corners_flush_snap_v2，window.content_geometry与采集快照包含snapTarget/titleOriginY。兼容列表打开记录workspace.display_options，现有重开日志继续记录具体结果。
