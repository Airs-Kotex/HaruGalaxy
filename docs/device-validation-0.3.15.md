# 0.3.15 / build21 设备验证

安装后先确认设置标题为0.3.15（21）。下列项目尚未完成真机或模拟器验收。

1. 普通多方向应用：在竖屏、左右横屏间反复旋转；内容应随工作区变化，不能停留在最初方向。
2. 运行时申请横屏的应用：进入全屏或横屏页面，确认不会随掩码未知回报反复切轴；退出后观察是否恢复。
   若退出仍横屏，记录操作顺序；重复横屏请求和方向先变的退出存在已知歧义。
3. 横屏专用与竖屏专用应用：前者首次打开及左右横屏切换正确；后者在横屏工作区保持支持方向。
4. 普通工作区、离开主应用后的浮动工作区，分别测试旋转锁定/解锁、启动时已横放、平放和斜角保持。
   同时检查系统方向来源是否实际收到回调；未收到时验证重力/UIDevice回退。
5. 后台恢复、解锁、新开窗口及关闭重开：不能被旧UIDevice缓存或旧回调转回错误方向；观察激活时是否卡顿。
6. iPad四方向、手机左右横屏；逐一检查自由/等比/原始画布、半屏/全屏、挂起与最小化恢复后的内容、
   四边触摸、安全区和窗口控制。竖屏工作区内最大化横屏专用内容还需确认可读性。
7. 回归原有新会话重置流程、单路播放、取消/拒绝/超时和锁屏恢复；键盘与其他图像问题不因本版离线通过而视为解决。

方向来源、托管请求/客户端回报和保留掩码只用于定位，不能替代画面和触摸观察。
遇到问题保留窗口、标记发生时刻并导出诊断，公开分享前隐藏设备、应用及会话标识。原始诊断不提交公开仓库。
