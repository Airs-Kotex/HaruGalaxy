# 0.3.13 / build19

用户最新指示为独立发布，保留0.3.12/build18，不再合并替换。版本0.3.2和0.3.11继续撤回。

## 输入证据与处理

FCCEA诊断包含22409条记录、20次启动；两次build18启动分别1079和158条。原始日志只在本地。原始画布重开后有应用仍为零图层，尺寸调整没有恢复它的画面。另一个应用有3个登记图层，其中2个非键盘；宿主部分visible记录来源是searchScreen，不能当作guest可输入的证据。本版没有可用的真机限时采集覆盖故障现场，不能确定具体触摸截断层。

缺少完整prepare/finish/add/remove接口时，停止主动guest选择及对应输入环境映射，保留主应用搜索。增加受限的已登记/已托管/未托管层类型、实际远程键盘窗口与来源匹配观察，图层变化自动采样。读取脚本默认只分析导出会话，可显式选择历史。没有录屏、按键、文本或剪贴板采集。

原“兼容显示”更名“原始画布”，明确它只调整布局，不宣称修复键盘或缺失画面。

## 执行、方向、iPad

最小化默认交给系统管理挂起；可选择BKS后台保活，申请仅针对该会话取得的PID，flags5保留PreventSuspend/AllowIdleSleep，不强制CPU高优先级。面板显示授权状态并随变化刷新。恢复、结束和交接释放请求；右上角实时挂起不变。系统可拒绝或撤销保活，后台任务与内存存活无保证。

使用成对UIDevice方向通知，平放保留上次有效值。UIKit横屏名称已反向映射到相同数值，因此不能再次交换3/4；有SDK命名静态断言。宿主视图内单独canvas按物理方向与UIWindowScene相对角旋转，guest尺寸/方向/安全区同轴，180度变化也触发布局。挂起内容在方向换轴时换逻辑宽高，恢复模型重排。保留iPad四方向及device families1/2，便携回归覆盖平板和分屏尺寸；无iPad真机确认。

## 明确关闭

用户报告关闭小窗后普通应用首次打开闪退，并授权无法无缝交接时结束应用进程。现有本地交接成功不证明普通渲染连续，因此使用其授权的结束进程兜底：明确Close先本地清理、立即以原RBSProcessHandle建立终止请求，不等待旧交接超时再发送。其余自动清理/显示模式重开仍只释放场景。

拒绝all-managed目标，不查bundle来结束替代进程、不发送数值PID终止信号；kill(pid,0)仅观察退出。使用上游固定entitlements.xml中terminateprocess权限名并检查实际请求结果。UI保留正在关闭状态，确认退出才移除；3秒仍处理中则显示pending并继续观察，不能把超时当作取消。拒绝保留错误和重试，手动结束后在能力检查前识别ESRCH。后台execute晚回调受完成状态保护。失败会话保存原handle，加载中Close等待该launch取得handle，失败/超时显示错误。未保存内容及同进程其他页面可能丢失。

独立复核发现并修正：横屏重复交换、保活面板缓存过期、窗口先消失再迟到结束、execute阻塞缺少pending提示、能力不支持时手动结束后无法清除记录。进程退出、权限授予与原生首次打开仍需要真机确认。
