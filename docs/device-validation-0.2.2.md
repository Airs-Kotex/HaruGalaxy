# 0.2.2 根视图启动回归复测

设备基线：iPhone 14 Pro Max / iOS 16.2。用户确认 0.2.1 点击开关立即报“系统没有提供可管理的浮窗根视图”，因此 0.2.1 未能验证黑屏和退出修复。

0.2.2 将实际根视图检查移到场景加入之后，等待 root 和窗口都连接再迁移工作台；不把初始化中的 nil 当作系统不兼容。最多等待 2 秒，超时或实际类型不兼容时清理并恢复普通模式。

## 最短测试

1. 用 0.2.2 / build 4 覆盖安装。
2. 空载点击“浮动工作区”，观察是否仍立即报错，或等待后才提示，或成功出现边缘入口。
3. 成功后检查背景是否可见、空白区域可操作，再关闭一次浮窗，确认未闪退。
4. 只有前三步通过后，从边缘入口打开测试 App，检查内容等比与触摸。
5. 如失败，导出本次 JSON 并给出路径。保留完整错误文本，尤其区分“对象类型不兼容”与“2 秒内未连接”。

新事件 `overlay.root_probe` 含 attempt、generation、result、viewClass、windowConnected。result：0 等待、1 根窗口已连接、2 实际不兼容。`overlay.root_ready` 只在当前 root 和窗口同时就绪时出现；取消或超时后旧任务不会激活窗口。

现有 binder 注销顺序和独立内容缩放容器保留。0.2.2 的真机结果尚未取得；不声称这次改动已通过设备验证。
