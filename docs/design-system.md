# 原生界面规范

## Color

使用 iOS 动态系统背景、标签和分隔线颜色。强调色为青色 `#0D8591`；图标基底 `#103F4C`、窗口面 `#E4FAF4`。红色关闭、橙色最小化、绿色最大化，同时使用 x / − / 放大图形区分动作，避免仅依赖颜色。

## Typography

采用 iOS 系统字体以配合中文和系统可读性。工作台主标题 32pt bold；空状态标题 24pt semibold；窗口标题 14pt semibold；正文 14–15pt。长应用名截断，搜索列表同时显示 bundle ID 以便区分同名 App。

## Layout

主工作台文字遵循安全区；窗口使用完整显示边界，不预留底部收纳区。窗口标题栏高 48pt，控制按钮触达范围 44pt；普通窗口圆角 18pt，全屏为 0。边缘入口触达区域 44×48pt，收起后显示 8×48pt 凸起，轻点打开面板，长按0.35秒后拖动移动。

自由模式改变 App 逻辑尺寸，等比模式固定逻辑画布并统一变换。左下手柄标“自由”，右下标“等比”。上半屏窗口为标题栏避让顶部，脱离时只移除避让区域，保持内容起点和尺寸。全屏隐藏本项目窗口 chrome，内容覆盖完整 bounds，边缘入口提供退出路径。

## Components

系统磨砂标题栏承载控件，内容区只承载实际应用场景或明确的加载/错误状态。关闭/缩放等按钮有辅助功能标签，设置中可减少动画。窗口面板锚定入口附近，列出窗口与收纳状态；外部点击遮罩只消费一次用于关闭，面板隐藏后移除命中。半屏预览只在自由模式拖动边缘停留后出现，不接受触摸。

原生 UI 没有在本环境实际渲染验证；以上是代码与资源中实现的设计规范，不能替代真机截图检查。
