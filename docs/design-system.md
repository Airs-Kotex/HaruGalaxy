# 原生界面规范

## Color

使用 iOS 动态系统背景与标签颜色。0.3.5 的操作层采用 Liquid Glass 风格：中性透明磨砂、细亮边、内侧高光和柔和阴影；活动边框使用低饱和青色。红色关闭、橙色最小化、绿色最大化，同时使用 x / − / 放大图形区分动作，避免仅依赖颜色。

## Typography

采用 iOS 系统字体以配合中文和系统可读性。工作台主标题32pt bold；空状态标题24pt semibold；窗口标题12pt semibold；正文14–15pt。长应用名截断，搜索列表同时显示bundle ID以便区分同名App。

## Layout

主工作台文字遵循安全区；窗口使用完整显示边界，不预留底部收纳区。窗口标题栏高28pt，标题栏按钮28pt，面板仍提供44pt操作行；普通窗口圆角18pt，全屏为0。入口触达区域56×76pt，直接拖动即可自由放置；仅释放位置距离左右边缘不超过18pt时吸附，贴边空闲后显示12×60pt凸起。未贴边时始终展开。轻点或原地长按松手打开面板。

自由模式改变App逻辑尺寸，等比模式使用系统完整画布并统一变换。0.3.9底部为8pt独立细边，整条可拖动等比缩放，guest内容在其上方结束；中央24pt短线以1.5pt线宽提示位置，接触加亮，不向guest区域扩张命中。右上自由角标为28pt并位于标题栏内。等比几何扣除28+8=36pt控件空间。标题栏允许从按钮处开始pan，识别后取消按钮tap。上半屏窗口为标题栏避让顶部，脱离时保持内容起点和尺寸。全屏隐藏窗口chrome，边缘入口提供退出路径。

底部没有按钮或文字。0.3.9移除复制输入板，面板“打开应用”恢复整行宽度。面板每行98pt，44pt操作行包含收纳、全屏、结束小窗并打开原应用、关闭；原应用动作的说明在面板标题下可见。键盘诊断入口在设置，开始后关闭设置并采集20秒，不干预焦点。

0.3.10按guest实际渲染矩形与宿主安全矩形计算边缘交集，除以显示比例后写入对应方向的场景安全区。移动至屏幕内部时恢复0，靠近Home区域时仅避让交集部分，不增加底栏高度。拖动/缩放期间合并几何更新，结束时提交最终值。

## Components

`MWGlassSurface` 统一入口、标题栏和面板的材质，使用 iOS 14+ ultra-thin material、静态高光和描边。面板圆角24pt、条目16pt；不嵌套昂贵的重复 blur。内容区保持实际 App 场景或明确的加载/错误背景。关闭/缩放等按钮有辅助功能标签，设置中可减少动画。窗口面板锚定入口附近；外部点击遮罩只消费一次用于关闭。半屏预览不接受触摸。

降低透明度时改为不透明系统背景，增加对比度时增强轮廓；深浅色变化会刷新动态色。效果层不覆盖 guest 内容，也不改变已有 touch hitTest 路由。此版本不包含 iOS 26+ 原生 UIGlassEffect，只在受支持旧系统上实现视觉兼容。参考 [Apple Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)。

原生 UI 没有在本环境实际渲染验证；以上是代码与资源中实现的设计规范，不能替代真机截图检查。
