# 原生界面规范

## Color

使用 iOS 动态系统背景与标签颜色。0.3.5 的操作层采用 Liquid Glass 风格：中性透明磨砂、细亮边、内侧高光和柔和阴影；活动边框使用低饱和青色。红色关闭、橙色最小化、绿色最大化，同时使用 x / − / 放大图形区分动作，避免仅依赖颜色。

## Typography

采用iOS系统字体。工作台主标题32pt bold，空状态标题24pt semibold，正文14–15pt。0.3.12移除窗口顶部应用名称，名称保留在窗口面板/搜索列表中。

## Layout

主工作台文字遵循安全区；窗口使用完整显示边界，不预留底部收纳区。窗口标题栏高28pt，标题栏按钮28pt，面板仍提供44pt操作行；普通窗口圆角18pt，全屏为0。入口触达区域56×76pt，直接拖动即可自由放置；仅释放位置距离左右边缘不超过18pt时吸附，贴边空闲后显示12×60pt凸起。未贴边时始终展开。轻点或原地长按松手打开面板。

自由模式改变App逻辑尺寸，等比模式使用系统完整画布并统一变换。0.3.12采用左上/右下等比、右上/左下自由。底部8pt独立细边分左右两半；顶部两角控件与中央四按钮互不重叠。控制条总占用仍36pt，App内容不被透明扩大命中区覆盖。窄窗自适应按钮宽度并留间隔。轻点不改形，14pt拖动后才开始缩放。

底部没有额外按钮或文字。面板顶部并列“打开应用”“挂起设置”；每个App有收纳、全屏、挂起/还原文字、关闭，省略号菜单另含原应用切换与兼容模式。设置标题含版本/build，快捷入口滚动定位挂起设置。键盘诊断仍为20秒被动采集。

0.3.10按guest实际渲染矩形与宿主安全矩形计算边缘交集，除以显示比例后写入对应方向的场景安全区。移动至屏幕内部时恢复0，靠近Home区域时仅避让交集部分，不增加底栏高度。拖动/缩放期间合并几何更新，结束时提交最终值。

0.3.12等比转换先缩入原frame与可用区域交集，再从对应对角固定点缩放。不会保留宽半屏宽度而把窗口撑到整屏高度。关闭/最小化/最大化/挂起在顶栏中间，挂起图形由原生矢量绘制以避免系统符号缺失。普通标题仍避让系统顶部，分屏区域不额外缩小。

0.3.12半屏吸附时顶栏贴该半屏上沿，不加整块safe-top spacer；普通非吸附窗口仍保留顶部可触达保护。半屏外框保持准确的半屏尺寸。内容的系统安全区另行传递，物理刘海/动态岛与系统手势不由布局绕过。

面板顶部现在并列“打开应用 / 挂起设置 / 兼容显示”三项，沿用44pt高操作行，在220pt宽的面板中每项约65pt，14pt文字。兼容显示打开显式列表，按App当前状态给出兼容/普通重开动作，关闭后才调用现有受保护重开流程。

README展示图由scripts/render_guides.py绘制，四张PNG各自标注“操作示意图 · 非真机截图”；用于解释操作，不是设备验证证据。控件绘图可适当放大，但不得伪装系统截图或展示未实现的功能。

挂起窗置于安全区右上方，圆角12pt，多个按列分布。默认最长边为可用区域短边36%，设置可调18%–50%；为容纳多个窗口会进一步缩小。外形比例可选原窗口/1:1/4:3/3:4/16:9/9:16；画面统一缩放且可能留边，整块缩略窗只处理还原点击。挂起不重排guest画布、不占键盘焦点，恢复使用完整窗口模型快照。界面设置改变缩略窗外形，不改变恢复快照。

## Components

`MWGlassSurface` 统一入口、标题栏和面板的材质，使用 iOS 14+ ultra-thin material、静态高光和描边。面板圆角24pt、条目16pt；不嵌套昂贵的重复 blur。内容区保持实际 App 场景或明确的加载/错误背景。关闭/缩放等按钮有辅助功能标签，设置中可减少动画。窗口面板锚定入口附近；外部点击遮罩只消费一次用于关闭。半屏预览不接受触摸。

降低透明度时改为不透明系统背景，增加对比度时增强轮廓；深浅色变化会刷新动态色。效果层不覆盖 guest 内容，也不改变已有 touch hitTest 路由。此版本不包含 iOS 26+ 原生 UIGlassEffect，只在受支持旧系统上实现视觉兼容。参考 [Apple Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)。

原生 UI 没有在本环境实际渲染验证；以上是代码与资源中实现的设计规范，不能替代真机截图检查。
