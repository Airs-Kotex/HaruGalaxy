# 原生界面规范

## Color

使用 iOS 动态系统背景与标签颜色。0.3.5 的操作层采用 Liquid Glass 风格：中性透明磨砂、细亮边、内侧高光和柔和阴影；活动边框使用低饱和青色。红色关闭、橙色最小化、绿色最大化，同时使用 x / − / 放大图形区分动作，避免仅依赖颜色。

## Typography

采用 iOS 系统字体以配合中文和系统可读性。工作台主标题 32pt bold；空状态标题 24pt semibold；窗口标题 14pt semibold；正文 14–15pt。长应用名截断，搜索列表同时显示 bundle ID 以便区分同名 App。

## Layout

主工作台文字遵循安全区；窗口使用完整显示边界，不预留底部收纳区。窗口标题栏高 48pt，控制按钮触达范围 44pt；普通窗口圆角 18pt，全屏为 0。入口触达区域 56×76pt，直接拖动即可自由放置；仅释放位置距离左右边缘不超过18pt时吸附，贴边空闲后显示12×60pt凸起。未贴边时始终展开。轻点或原地长按松手打开面板。

自由模式改变 App 逻辑尺寸，等比模式使用系统完整画布并统一变换。0.3.7 普通窗口增加44pt独立底栏，guest 内容在底栏上方结束。右下系统等比角标位于底栏，使用完整44×44pt命中区域、淡色底和接触加亮；右上自由角标保留44pt四分之一圆命中。等比几何扣除48pt标题栏与44pt底栏。标题栏允许从按钮处开始 pan，识别后取消按钮 tap。上半屏窗口为标题栏避让顶部，脱离时保持内容起点和尺寸。全屏隐藏窗口 chrome，边缘入口提供退出路径。

底栏另有键盘和打开原应用两个44pt按钮。输入板在普通应用场景使用UITextView，全屏时从面板进入；短横屏收起提示，原应用动作移至导航栏，保留键盘上方的编辑空间。面板每行仍为98pt，操作行从三个按钮变为四个，窄面板仍保留44pt以上触达宽度。

## Components

`MWGlassSurface` 统一入口、标题栏和面板的材质，使用 iOS 14+ ultra-thin material、静态高光和描边。面板圆角24pt、条目16pt；不嵌套昂贵的重复 blur。内容区保持实际 App 场景或明确的加载/错误背景。关闭/缩放等按钮有辅助功能标签，设置中可减少动画。窗口面板锚定入口附近；外部点击遮罩只消费一次用于关闭。半屏预览不接受触摸。

降低透明度时改为不透明系统背景，增加对比度时增强轮廓；深浅色变化会刷新动态色。效果层不覆盖 guest 内容，也不改变已有 touch hitTest 路由。此版本不包含 iOS 26+ 原生 UIGlassEffect，只在受支持旧系统上实现视觉兼容。参考 [Apple Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass)。

原生 UI 没有在本环境实际渲染验证；以上是代码与资源中实现的设计规范，不能替代真机截图检查。
