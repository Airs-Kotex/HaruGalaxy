# 0.3.12 撤回与四角布局修正

用户要求删除0.3.11发布。GitHub release439977139及6个附件已删除，公开tag-release查询404；源码/tag未删除，保留历史。README先恢复0.3.10下载入口，提交4875478。旧包留本地用于调查；不会重发0.3.11。

用户澄清半屏问题：宽半屏进入原始比例会突然变得很高，使顶边与底边受屏幕边界夹住。旧MWBeginProportionalResize保留宽度再fit全viewport；使用原逻辑运行390×375半屏实例，`new.height<=old.height`断言失败。新实现取原frame与可用区交集，在内部等比fit，不扩大高度，转换后重置pan translation，之后由对应对角锚点缩放。

四处入口按要求映射：TL/BR等比，TR/BL自由。顶部两角为专属header区域，底部8pt rail分两半，不覆盖guest。关闭/收纳/全屏/挂起四按钮居中，删除顶部名称；窄窗按钮自适应缩小并留缝。等比转换可得到低于220pt宽窗口，因此resize/reflow/保存/恢复同步保留现有小尺寸，避免后续又弹大。新窗仍有正常默认尺寸。

独立复核发现旋转后的约54pt短窗容不下47pt顶部安全区，bar和controls的不同clamp可能把按钮裁到bar外。已统一bar和按钮源矩形，并在短窗高度不足时仅移动至可操作区域，保留宽高比例；回归覆盖37–170pt高度、59pt安全区及具体38.815×53.936案例。

挂起0.3.11源码及构建包存在，但用户设备无入口的原因尚未由日志证实；不虚称已定位。0.3.12顶部挂起改用本地UIKit绘制模板图标，面板增加“挂起/还原”文字与“挂起设置”快捷入口，菜单也有相同动作。设置标题显示版本/build，日志记录控件安装与布局版本；这改善可发现性并提供版本核对，不等同真机显示验证。

按用户先前授权保留挂起状态/比例设置、兼容显示及渲染诊断。870/Telegram和guest键盘问题仍未宣称修复。发布以0.3.12/build17单独提供，具体验证附件记录。
