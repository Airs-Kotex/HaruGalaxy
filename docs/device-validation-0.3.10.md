# 0.3.10 底部按钮与输入检查

版本0.3.10/build15。基于用户提供的0.3.9诊断3B51进行代码修正；原始诊断不进入仓库。

| 检查 | 操作与预期 |
| --- | --- |
| 对比位置 | 同一个App分别置于屏幕中间、贴底、全屏，点击同一个底部按钮；记录哪个位置失效 |
| 对比模式 | 右上自由缩放与底部系统等比分别尝试；内容按钮不应被8pt细边当作缩放操作 |
| 诊断采集 | 保留问题窗口后在设置开始20秒采集，再点击底部按钮、标题栏、底部缩放条各一次；导出本版日志 |
| 安全区 | 贴底/全屏时观察App底部工具栏是否上移避开Home区域，移回中间后恢复；目标App可能不遵循安全区 |
| 横屏 | 横屏侧边及底部安全区随方向更新，比例/画面不额外拉伸 |
| 键盘 | 尝试文本框，记录光标、键盘画面、能否输入三项；iOS16.2缺少PID接口时不应再出现本应用主动prepare的托管键盘 |
| 原应用 | ↗仍经兼容交接后打开，不遗留面板遮罩；不以accepted日志替代画面确认 |

重点字段：`keyboard.hosting_skipped`、`input.window_touch.region`、`bottomHitProbes`、`railOverlapsContent`、宿主`safeInsets`与guest`safeAreaRequested/safeAreaReported`。底部探针是宿主window的合成查询，不向App发送点击；`guest_surface`命中不证明WindowServer已经把真实触摸交给guest。实际触摸没有到达宿主，也不证明guest未收到。

若需要一条最简反馈，请注明：App名称、按钮名称、自由/等比/全屏、窗口是否贴近手机底边、是否先点过文本框。诊断不记录文本、按键或原始点击坐标。
