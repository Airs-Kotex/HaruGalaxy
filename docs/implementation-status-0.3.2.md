# HaruGalaxy 0.3.2 实施记录

本版回应“收起后经常无法唤出”和继续改善流畅度的反馈。源代码检查发现原入口可见宽度仅 8 点，点击/长按识别相互独立，动画未允许交互，面板每次重建全部条目，普通前台生命周期通知同步等待日志落盘。这些是已识别的代码风险，没有新设备 trace 可将某一项认定为唯一根因。

入口使用固定 56×76 点控制区域，收起可见 12×60 点凸起，展开宽 44 点。单一 UIControl 跟踪路径调用生产 C 手势模型：轻点允许小幅漂移，向内短拉可唤出，原地长按后松手也可开面板；长按振动后继续移动才移位。先用测试复现了“振动前 8 点偏移，振动后停住却触发移动”的问题，再把拖动基准改为振动时位置。主动隐藏、窗口替换、视口变化会取消跟踪，待执行的计时器以代际标记失效。

入口收放动画允许触摸，从当前动画位置继续；正在触摸、移动或打开面板时暂停自动收起。跨左右边缘后显式刷新贴边方向。新增持久化选项“入口保持展开”，默认仍为小凸起。触摸区扩大也意味着该范围会接收入口手势，README 和验收文档说明可移位避开 App 控件。

面板按 App 标识保留条目，用名称、状态、全屏和顺序快照跳过无变化更新；关闭后释放不存在的条目。普通拖动不再布局隐藏面板；未变化的活动边框与角标不重复设置，主题变化仍刷新边框。普通前台生命周期和问题标记改为串行日志队列异步 flush，退出后台/终止/未捕获异常仍有同步落盘边界。

新增入口触摸结果、面板同步准备耗时与累计条目创建数，保留本机滚动日志和用户主动导出。没有自动上传、输入文字记录或设备 FPS 测量。场景启动、binder 销毁和根窗口原生触摸路由保持既有实现；此版不宣称验证所有 TrollStore 系统或解决私有接口全部限制。

版本 0.3.2 / build 7，Bundle ID 继续使用 `io.github.airskotex.harugalaxy`。发布包含原生安装包、源码包、摘要与离线验证报告；SDK、下载缓存和原始用户诊断不分发。真机复测内容见 [0.3.2 验收](device-validation-0.3.2.md)。

验证完成：主机 C/诊断测试、26 个生产翻译单元的 Clang 静态分析、启用警告即错误的原生编译、离线签名权限与包结构校验，以及不含 Git 元数据的源码副本测试/构建。独立源码复核在上述手势修正后无阻断发现，未代替真实 UIKit 事件验证。发布制品的具体源码提交和摘要记录于随包验证报告。
