# 0.3.12 四处缩放与挂起入口

先检查设置标题应显示0.3.12(17)。0.3.11发布已撤下。用户反馈挂起入口缺失，没有新的设备版本日志，源码/包包含入口不能等同设备可见。

| 检查 | 操作与预期 |
| --- | --- |
| 四入口 | 左上等比、右上自由；底边左半自由、右半等比，分别从四处开始拖动 |
| 上半屏转等比 | 上半屏后从右下拖动，初次转换不大于原半屏范围；再从左上拖动可缩回，不被整屏高度锁住 |
| 下半屏/横屏 | 下半屏、横屏左右半屏分别转换；对角固定、尺寸始终在显示范围内 |
| 轻点/取消 | 任一入口轻点或小抖动不改形；拖动期间锁屏/旋转/打开面板后取消回原状态 |
| 顶部四按钮 | 顶部中央依次关/最小化/最大化/挂起，不出现应用名称；按钮和两角缩放控件不重叠 |
| 挂起文字入口 | 面板每行有“挂起”，挂起后显示“还原”；顶部“挂起设置”直接定位大小/比例 |
| 自绘图形 | 顶部第四个蓝色图形可见；系统缺少pip.enter符号也应有应用绘制的图形 |
| 小窗记忆 | 从半屏转等比产生较窄窗口，关闭重开/挂起还原/全屏还原不会重新放大到220pt宽 |
| 极短窗口 | 小窗口旋转后再切自由模式、拖到屏幕最上方；顶栏和按钮同一位置，短窗会移到可触达区域，不裁掉四按钮 |
| 保留功能 | 兼容画布、日志导出、入口自由拖动、原应用切换和挂起恢复保持可用 |

日志新增window.controls_installed与settings.controls_installed，记录布局标识、控件/图形存在、version/build。resize_contact/begin/finished带corner编号0左上/1右上/2左下/3右下。诊断不记录输入内容；控件安装记录不能证明它被远程窗口系统正确显示。
