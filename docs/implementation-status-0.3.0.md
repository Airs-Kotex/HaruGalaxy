# 0.3.0 实施记录

依据用户已确认的0.2.2后台可用结果，本轮保留 Platform 后端，包括启动等待、root透明/命中、binder注销和持续执行请求。

UI改为单次轻点打开边缘窗口面板，长按后拖动移动入口，设置从面板进入。最小化不再创建底部条或预留屏幕空间。空白点按仅关闭面板，命中查询本身不改变焦点。

窗口默认自由模式，左下手柄自由改变尺寸并更新App场景逻辑尺寸；右下手柄固定当前画布并等比缩放。全屏使用完整bounds且隐藏自己的标题栏，借助边缘面板还原。自由模式标题拖向边缘停留后提供半屏预览，松手提交，取消恢复原状态。

复核修正上半屏窗口脱离吸附时的顶部空间跳变：移除59pt避让空间的同时将框下移59pt，保持guest全局起点和尺寸；对应回归测试验证自由/等比的零增量起点一致。

状态测试扩展覆盖自由缩放锚点、屏幕约束、全屏还原、半屏旋转及顶端避让连续性。交互日志保留模式、预览、提交和取消动作。实际系统栏、remote guest触摸与手势冲突需下一轮真机确认。
