# HaruGalaxy 0.3.1 / 初春星河 真机验收

沿用 iPhone 14 Pro Max / iOS 16.2 的用户反馈：后台浮窗可用，0.3.0 仍有搜索键盘、当前比例语义、左下角遮挡、下半屏可达性、顶部限制及卡顿问题。本版的代码/构建检查不代表这些问题已获真机确认。

| 项目 | 操作与通过条件 |
| --- | --- |
| 升级与名称 | 安装0.3.1/build6；中文显示初春星河，英文显示HaruGalaxy；新Bundle ID可与旧版并存，设置/日志独立 |
| 搜索键盘 | 从边缘面板打开应用选择器，点搜索；检查输入法、输入文字、取消与选择是否正常 |
| 输入兼容路径 | 键盘未显示时点“在主应用中输入”；正常scene能搜索，选中/取消后恢复原浮窗和已有会话 |
| 输入取消/锁屏 | 输入转场时退后台、锁屏、关闭浮窗后不残留透明遮挡，不让旧回调结束新搜索 |
| 系统原始比例 | 先自由拉成宽窗，再拖右下弧线，恢复系统完整画布比例；竖屏430:932、横屏932:430为本设备逻辑尺寸示例 |
| 右上自由缩放 | 左下锚点不动；内容按新宽高排版；手柄只有细弧，内部点击传给App |
| 右下等比缩放 | 统一缩放、触摸落点准确，不沿用自由拉伸后的比例 |
| 下半屏 | 从中部向下拖标题，让窗口下边接近屏幕底部；手指仍在屏幕中部即可出现预览，松手下半屏 |
| 顶部移动 | 普通窗口可拖到y=0，未被safeTop拦住；硬件动态岛遮挡不视为软件可绘制区域 |
| 流畅性 | 对比0.3.0连续移动/缩放；记录抖动是边框、内容重排还是触摸延迟，提供日志与步骤 |

新增诊断：`search.focus_request`、`search.keyboard_check/shown`、`search.main_scene_*`、`overlay.search_input`、`window.resize_finished`（duration、sceneUpdates）。不记录query文本。

拖动不应更新App逻辑尺寸；自由缩放按显示刷新合并场景更新并最终提交；等比模式只在进入系统画布或方向变化时更新逻辑尺寸。没有设备帧时间测量时，不宣称已经达到某个FPS或完全消除卡顿。
