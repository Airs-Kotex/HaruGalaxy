# 0.1.0 Alpha 真机验收

**当前记录：全部设备项目尚未执行。** 本轮仅完成 Linux 主机测试、交叉编译、静态检查和包结构校验。

测试设备信息须在开始时填写：设备型号、iOS/iPadOS 精确版本及 build、TrollStore 版本、安装包 SHA-256。

上游已有键盘、单场景 App 和关闭重开方面的限制。本项目调整了自身生命周期，但没有实机证据证明这些系统限制均已解决。

如出现空窗或触摸异常，先记录应用名称和版本、发生在普通/浮动模式、启动时是否已在后台，再收集相关崩溃日志。Presenter 对象存在只表示呈现对象创建成功，不能当作首帧渲染成功。
