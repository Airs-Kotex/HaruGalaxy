# 0.3.0 交互验收

用户已确认 0.2.2 可以在 iPhone 14 Pro Max / iOS 16.2 后台通过悬浮窗使用应用。0.3.0 保留该 Platform 后端，仅调整 UI/几何及主窗口系统栏偏好；以下新增行为仍未取得真机结果。

| 操作 | 预期结果 | 当前证据 |
| --- | --- | --- |
| 轻点边缘凸起 | 一次打开窗口面板，再点关闭；不移动入口 | 代码复核；设备待测 |
| 长按0.35秒并拖动 | 振动后才移动；松手吸边并记忆，不打开面板 | 代码复核；设备待测 |
| 面板外点按 | 只关闭面板，该次触摸不操作下面的 App | 层级与命中复核；设备待测 |
| 最小化 | 窗口收入面板，屏幕底部没有收纳条或额外空白 | 代码检查；设备待测 |
| 面板条目恢复 | 还原窗口，内容/状态保留，无重复创建 App 场景 | 代码复核；设备待测 |
| 左下自由缩放 | 右上角固定，宽高可独立变化，App 重排 | Core 几何测试；设备待测 |
| 右下等比缩放 | 左上角固定，保留开始时的内容比例 | Core 测试；触摸待测 |
| 两种手柄连续切换 | 不需要全局开关，每次按该角语义执行 | 代码复核；设备待测 |
| 标题栏拖边停留 | 自由模式0.2秒后显示半屏预览，移开取消 | 代码复核；设备待测 |
| 预览后松手 | 竖屏上/下半屏，横屏左/右半屏 | Core 几何测试；设备待测 |
| 上半屏再缩放 | 标题栏可操作，开始拖动时内容不跳变 | 430×932/顶部59pt回归测试；设备待测 |
| 最大化 | 进入全屏、标题栏及手柄隐藏，内容延伸到底部 | Core 全bounds测试；系统栏待测 |
| 全屏还原 | 边缘面板的还原操作恢复原尺寸、模式和半屏位置 | Core 状态测试；设备待测 |
| 旋转 | 全屏保持铺满；半屏按方向重排；普通窗口可触达 | Core 测试；设备待测 |
| 系统打断手势 | 取消移动/缩放时恢复原状态，不提交半屏 | 源码复核；设备待测 |
| 后台/锁屏/关闭浮窗 | 与0.2.2功能一致，UI改动未影响后台 | Platform 源码未改；设备回归待测 |

全屏几何不再排除任务栏区域，主窗口请求隐藏状态栏和自动隐藏 Home 指示条。系统手势、全局系统层及硬件遮挡不能仅靠窗口尺寸强行移除。若底部仍有系统指示条，请说明是否只是细线、是否有留白、是否能正常触摸最下方内容。

反馈时通过窗口面板 → 设置 → 真机诊断 → 标记问题 → 导出 JSON。新事件：`edge.tap`、`edge.move_begin/end`、`panel.open/close`、`window.resize_begin`（free/proportional）、`window.snap_preview/committed`、`window.fullscreen`、`window.gesture_cancelled`。
