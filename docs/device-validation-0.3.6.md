# 0.3.6 设备检查

版本0.3.6，沿用 iPhone 14 Pro Max / iOS16.2（20C65）反馈。主应用搜索键盘在0.3.5已确认可用，guest键盘仍待定位。

| 项目 | 操作 |
| --- | --- |
| 入口直接拖动 | 无须等待振动，按住即拖到屏幕中间；释放后不贴边，重新打开应用位置保留 |
| 边缘吸附 | 从中间拖到左/右边缘附近释放，空闲后收成凸起；仍可轻点打开 |
| 居中入口面板 | 入口停在中间时打开面板；横竖屏都应可操作列表条目，入口不挡住按钮 |
| 取消与旋转 | 拖动中锁屏、旋转、关闭浮动模式；取消不误开面板，再次拖动可用 |
| 窗口标题栏 | 从空白标题和按钮区域分别拖动；移动时不关闭/最小化，普通点按钮仍有效 |
| 右下等比 | 在弧线附近按下应加亮；向任意方向拖动改变大小，保持系统原始比例 |
| 右上自由 | 自由调整宽高；角落以外的App按钮和滚动仍正常 |
| 主搜索 | 在主应用输入中文、英文，确认0.3.5已恢复的功能没有回归 |
| guest请求 | 选中两个不同App的文本框各尝试一次；观察是否有光标、键盘及输入响应 |
| 切换/关闭 | A输入时切到B，最小化/关闭B；无旧键盘残留或错误输入归属 |

请在尝试guest输入后标记问题并导出该版本日志；旧0.2.x包不能解释当前问题。可关注：

- `keyboard.guest_input_state.systemInputActive`：guest是否报告输入活动。
- `keyboard.presentation_prepared`：是否执行成对显示准备、是否返回窗口。
- `keyboard.focus_observed`：请求后状态是否改变、`sourceScene`和窗口可见性。
- `keyboard.presentation_cleanup_failed` / `hosting_cleanup_failed`：是否因旧关系清理失败而停住。
- `window.resize_contact` 与 `window.resize_begin`：右下触摸是否命中、是否开始缩放。
- `edge.move_begin/end`：是否开始拖动、结束坐标与是否贴边。

准备/请求/回调存在均不等于系统显示了键盘，须结合画面和该时刻日志。
