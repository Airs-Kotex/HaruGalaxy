# 0.3.14 / build20 设备验证

设置页核对0.3.14(20)。目前只有旧版iPad日志，没有本版实际画面/触摸/音频结果。

1. iPad竖屏打开可横屏App，转两侧横屏与倒置；再从横屏启动小窗。确认内容不竖排/裁切，窗口左右边缘按钮可点，安全区对应当前方向。
2. 分别在系统旋转锁定/解锁、浮动工作区离开主应用后旋转。平放保持原方向，检查orientation.motion_receiving和样本年龄；传感器不可用应明确记录。
3. 自由/等比缩放、半屏、全屏、右上挂起、最小化后旋转恢复。日志的scene requested/native/reported frame、presenter bounds、normalization必须一起检查；设置请求本身不证明显示成功。
4. 原应用先播放视频，再从窗口面板打开同App。观察“结束原应用播放→重新打开小窗”，旧进程退出后才建立新场景。在小窗播放时确认只有一组声音。此步骤会重置原App，先保存需要的内容。
5. 重置处理中关闭窗口、退出浮动模式、点击原应用菜单或切画布；不得重新拉起取消的小窗、提前打开将被结束的旧进程、重复结束替代进程。
6. 系统拒绝/仍在处理时应显示状态。手动从系统多任务结束后恢复；没有确认退出不得创建双场景。单独检查不同App同时播放未被全局暂停。

遇到问题保留当时的小窗，立即标记并导出日志。日志只记录状态，无输入文本、音频或画面；原始诊断不公开提交。
