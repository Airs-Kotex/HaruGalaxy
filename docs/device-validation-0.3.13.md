# 0.3.13 / build19 设备核对

本轮没有可连接的iPhone、iPad或iOS模拟器。操作图仍标注为示意图。安装后设置标题应为0.3.13(19)。

1. 设置→浮动工作区→最小化行为，切换系统挂起/保活。对已最小化App立即应用，面板授权状态与日志一致。恢复/关闭后不再持有guest assertion；锁屏不显示小窗或键盘。
2. iPhone两侧横屏、竖屏、平放；分别在系统方向锁定/解锁下操作，确认外框、内容及触摸方向一致，不倒置、不双重旋转。iPad补充倒置竖屏和不同可用窗口大小。
3. 在上/下或左/右半屏、自由/等比、全屏、最小化、右上挂起状态旋转并恢复。检查四角控件、安全区、面板/入口和旧位置可触达。
4. 小窗中点文本框和底部按钮，检查不可见键盘是否仍占触摸区域；自动图层变化采样仍不够时，采集20秒诊断。主应用搜索仍应可输入。不能将keyboardVisible或layerCount代替可用性结论。
5. 红色关闭：观察“正在结束”到消失后，从主屏幕打开一次。复测启动中关闭、最小化后关闭、失败后关闭。系统拒绝时保留错误，手动从系统多任务结束后重试。pending时不要认为已取消请求。检查未结束其他进程。
6. 原始画布是布局选项。零图层应用、870和Telegram图像问题继续单独记录，不将重新创建presenter视为修复。

导出本机诊断，记录实际机型、OS build和所处模式。日志不自动上传，也不要提交原始诊断到公开仓库。
