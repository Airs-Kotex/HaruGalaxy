## 产品与边界

面向 TrollStore 用户的原生 iOS 多窗口工具，参考 UiharuX 的能力与 MilkyWay 的窗口操作。提供应用选择、真实场景承载、拖动、缩放、最小化、恢复、最大化、关闭与中文设置。源码与可安装 Alpha 包是本次交付目标；设备运行和兼容性验收单独记录。

最低编译部署目标为 iOS 15.0，arm64。实际支持须在 TrollStore 可用系统上逐台验证；不声明 iOS 15–17 全覆盖。上游已知键盘、单场景应用和后台问题必须保留在实机验收中。

## 结构

- `Sources/Core/`：可在 Linux 测试的 C 状态与几何规则；处理窗口边界、最小尺寸、最大化前位置和合法状态转换。
- `Sources/Platform/`：FrontBoard 场景会话、已安装应用枚举、设备能力检测、浮动根场景。私有接口集中在这里。
- `Sources/UI/`：原生 UIKit 工作台、悬浮入口、应用选择器、窗口标题栏、收纳条及偏好。
- `Resources/`：应用清单、权限及原生资源。
- `scripts/`：环境检查、构建、签名、打包与产物校验。

采用 FrontBoardAppLauncher 的场景机制；复用时记录来源和修改。全局浮动根场景首先使用其 presentation binder 机制，TrollSpeed 作为窗口生命周期参考。本次不引入另一套 root HUD 和模拟触摸注入机制，以便先验证一种完整的事件/场景路径。

## 行为契约

应用选择返回 bundle ID，创建唯一 scene ID 后启动进程并取得真实 presenter。后台以能力检查发现缺失类/方法时返回错误，不创建假内容窗口。启动有超时与取消，关闭后晚到的异步回调不能重新附加场景。

关闭窗口只销毁该窗口创建的 scene，失效其 presenter；绝不向被承载应用发送进程终止信号。一个 bundle ID 最多保留一个会话，再次选择时聚焦或恢复已有窗口。最小化保留会话和原位置，最大化受安全区约束，再次切换恢复原矩形。横竖屏变化重新约束几何。

系统后台显示使用独立、可停止的浮动根场景。只允许对本进程自己的浮动根场景拦截相关状态更新；关闭悬浮模式后不再抑制更新。锁屏时隐藏内容并在解锁时重新评估显示。空白区域穿透命中，窗口工具栏保持可触达。

最近使用记录 bundle ID（最多 12 项）及窗口几何；重启不自动启动第三方应用。偏好包含深浅色跟随、动画与浮动模式开关。默认不开启未经实机验证的后台浮动模式，用户可在设置中启用实验性浮窗。

## 界面

中文原生工作台，深浅色自适应，蓝青色强调。标题栏为磨砂材质，三个清晰的关闭/最小化/最大化按钮；拖动标题栏移动，右下手柄缩放，标题栏双击最大化/恢复。操作按钮触达区域至少 44 点。最小化窗口保留在可滚动应用条，点击恢复。应用选择器支持搜索、最近使用、应用图标；空状态、启动中和失败重试明确可见。
