# 0.3.0 窗口交互改进

用户已确认 0.2.2 可以在后台通过悬浮窗使用应用。新增要求：触摸动作更清晰；窗口最大化铺满屏幕；最小化收进悬浮入口；自由/等比缩放分别使用两角手柄；自由模式提供无按钮半屏快捷手势。继续在已授权的工作副本执行，后台启动与 binder 清理不在本轮变更范围。

## 动作规则

- 轻点边缘凸起一次打开/关闭锚定在入口旁的窗口面板。取消“第一次仅展开、第二次打开 App”的双阶段动作。
- 入口长按 0.35 秒后振动，保持按压并拖动才移动。移动/取消后不会触发轻点；设置改为面板里的明确按钮。
- 面板列出所有窗口及状态，最小化条目点按恢复；另有打开 App 和设置。点击面板外部仅关闭面板，并消费这一次点击，避免误触下面的 App。
- 最小化只隐藏窗口、收进面板，不保留底部收纳条，不占用手机底部。
- 标题栏单击聚焦、拖动移动、双击最大化/恢复；红黄绿按钮及两角手柄从标题栏手势命中中排除。
- 左下角自由缩放：固定右上锚点，改变宽高，App 接收新的逻辑视口并重新排版。默认新窗口使用自由模式。
- 右下角等比缩放：锁定开始拖动时的内容比例，固定左上锚点，保持逻辑画布并统一缩放。两种模式不通过模糊的按钮开关切换。
- 自由模式拖动标题栏靠近屏幕边缘，停留 0.2 秒显示半屏预览及轻触反馈，松手才吸附。竖屏上下半屏，横屏左右半屏；移开取消预览。拖动被系统取消时恢复原窗口，不执行吸附。

## 全屏

最大化使用 windowScene 的完整 bounds，不再扣除工作台标题、底部收纳区、安全区或固定比例。最大化时隐藏本项目窗口标题栏与缩放手柄，guest 内容覆盖完整窗口；可从一直可达的边缘面板还原/最小化/关闭。请求主窗口隐藏状态栏及自动隐藏 Home 指示条，并将 guest 场景设置为完整尺寸。不能承诺绕过系统手势、动态岛/硬件遮挡或全局系统层的规则；这些效果需真机确认。

半屏窗口内容仍保留标题栏，靠近系统顶部时将标题控件放在可触达区域。普通移动/缩放采用完整 bounds 内的边距，不预留旧底部收纳区。

## 实现边界

- Core 增加 free/aspect resize mode、free resize anchored-left、half-screen placement、full-screen/restore geometry；纯 C 测试覆盖模式切换、比例、全屏与半屏边界、旋转和取消。
- `MWWindowView` 管理手势、当前模式、预览回调、guest 逻辑画布；临时视图变换与系统视图分离，resize 期间短暂节流场景更新并在结束时提交最终尺寸。
- `MWWindowPanel` 为锚定面板，工作台拥有窗口列表和所有操作；面板显示时遮罩消费外部点击，关闭时移除遮罩。
- 触摸日志记录入口操作、缩放模式、半屏预览/提交、全屏/恢复、面板打开/关闭和窗口状态。

## 验证

保留 0.2.2 已有状态/启动/日志测试。新增布局测试与源码复核，编译 arm64/iOS14 并检查签名包。设备需要确认：入口长按移动不打开面板、轻点不移动、面板外点击不透传、两角缩放、半屏停留/松手、全屏系统栏表现及恢复路径。不能用本地测试代替这些 UIKit 实机动作。
