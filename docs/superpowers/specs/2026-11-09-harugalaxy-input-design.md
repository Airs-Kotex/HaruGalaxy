# HaruGalaxy 0.3.1 输入与手势修订

用户要求：悬浮入口的搜索可调起键盘；等比使用系统原始画布比例；自由/等比手柄迁到右上/右下并显示细小弧线；下半屏快捷操作可达；普通拖动能进入顶部状态区域；交互更连贯。追加品牌：英文 HaruGalaxy、中文 初春星河。安装标识和原工作副本保持不变以延续升级数据。

## 明确行为

- 右上角细弧：自由缩放，固定左下角；右下角细弧：以当前屏幕方向下的系统完整逻辑画布缩放，不取用户自由拉伸后的比例。进入等比模式先恢复原始比例。
- 弧线只占角落约14pt，不画大块背景；命中区限制在边缘L形带，内部区域穿透给内容。操作期间角标强调，辅助功能标签标明语义。
- 普通拖动不扣顶部safeTop，完整屏幕范围可达；不把物理动态岛遮挡宣称为可绘制区域。
- 半屏检测由拖动方向和未裁剪的窗口边界决定，距离对应屏幕边48pt且移动超过24pt时可预览，停留0.18秒后松手吸附。竖屏上下，横屏左右；无需把手指拖到Home手势区。
- 拖动只移动，不改变App逻辑尺寸；自由缩放合并重复布局，场景尺寸更新限频且结束必提交最终值。等比缩放不在每次采样更新App场景尺寸。

## 搜索输入

先确保搜索所在窗口key状态，并在可见层级内请求first responder，观测真实keyboard通知，不把becomeFirstResponder返回true当作键盘已显示。

如浮动scene未获得系统键盘权限，提供明确的“在主应用中输入”入口：激活现有主scene并在该正常scene呈现应用选择器，暂时隐藏浮动内容；选中/取消后恢复浮动窗口。保留搜索文本但不记录输入内容。该兼容路径不终止guest会话，也不猜测未验证的系统键盘私有方法。普通scene不可激活时返回错误，恢复overlay。
