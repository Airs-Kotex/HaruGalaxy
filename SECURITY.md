# Security reports

Do not post credentials, private diagnostic logs, or sensitive device contents in public issues. Diagnostic exports are local and user-controlled, but can include device information and identifiers of the applications involved in a test.

For a security issue, use [GitHub private vulnerability reporting](https://github.com/Airs-Kotex/HaruGalaxy/security/advisories/new) when available. If it is unavailable, open an issue requesting a private contact route without publishing exploit details or private data.

This is an experimental TrollStore application using private system interfaces. Report the precise app version, iOS build, affected operation, and impact. No claim is made that every TrollStore-supported device or API combination has been tested.
